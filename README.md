# Extractor drift manufactures phantom longitudinal associations in text-mined health cohorts

Release snapshot for the npj Digital Medicine submission (branch `release/npj-dm-v1`, single commit, no internal history).

This repository contains the analysis code, the double-annotated gold-standard benchmark, all result artefacts, figures, prompts and the annotation codebook for the manuscript. The study measures how text-extraction agreement varies across calendar years in a seven-year health-checkup cohort (2018–2024, 30,677 individuals, 121,283 classifiable ECG narratives), demonstrates that extractor version switching can manufacture phantom longitudinal associations, and releases a frozen-extractor governance protocol.

Pre-registration: OSF `10.17605/OSF.IO/KUMVE` (sampling plan, acceptance gates, extractor comparison and falsification rule; registration timing statement included).

## Repository layout

```
code/     Analysis pipeline (Python 3.11 + Node.js 18; unified CLI: sample / extract-dict / extract-llm / validate / manifest)
data/     Gold-standard benchmark: sampled reports, narrative text, pseudo-identifiers, extractor manifest
results/  Agreement, acceptance, bias-grid, replay and audit artefacts referenced by the manuscript
figures/  Figures 1–5 and Supplementary Figure 1 (PNG 300 dpi + PDF)
docs/     prompts/   Frozen LLM prompts (ECG v1, cardiac-ultrasound v2.1; SHA-256 prefixes registered in data/extractor_manifest.json)
          codebook/  Annotation manual v1.0/v2.0, column definitions, dataset descriptions (MD + PDF; authored in Chinese at the source institution — English summaries are given in the manuscript Methods and Supplementary Note 3)
```

## Data (CC BY-NC 4.0)

- `data/gold_ecg_H.csv` (n=570), `data/gold_abdus_H_300.csv`, `data/gold_abdus_PG_300.csv`, `data/gold_echo_PG_300.csv` (n=300 each; the 600-report rule-stratified sampling parents are reproducible from `code/01_*` and are not redistributed).
- Every record carries `sample_id` (release join key), `pseudo_id` (12-character salted-hash person key generated by the data provider before delivery; the salt is not distributed), `text` (verbatim de-identified narrative), year/exam date, and annotation columns in the workbook. No direct identifiers are included; the 600-report community-cohort sampling frame is not part of this release.
- The adjudicated gold standard is in `data/gold_annotation_workbook_final.xlsx` (final double-annotation workbook with arbitration outcomes; 4 sheets, 1,470 reports).
- `results/pii_scan_summary.csv` documents the automated PII screening applied before release.

## Code (MIT)

Naming map: the manuscript's **dictionary v1** and **dictionary v3** correspond to dict v1/v3 in `code/07_dict_v3_rerun.py` and `code/main.py extract-ecg`. An internal intermediate v2 existed only for exploratory annual-rate tabulations during protocol development and was superseded by v3 before the validation study; it never entered the analysis database and is not part of this release.

Key entry points: `main.py` (unified CLI), `01_*` sampling, `04_agreement_stats.py` (κ/AC1/F1), `23_m2d_acceptance.py` / `29_ecg_acceptance.py` (acceptance gates), `27_m5b_simex_backfill.py` + `33_grid_simcheck.py` (κ→HR grid), `32_phantom_ci.py` (Table 1), `35_phantom_differential_replay.py` (Supplementary Fig. 1), `30_audit_verify.py` (83-claim number audit). LLM serving is local (Ollama; Qwen2.5-14B/7B-Instruct, GLM-4-9B; temperature 0, seed 42); determinism holds within identical software/hardware environments and is not guaranteed bit-for-bit across runtimes.
