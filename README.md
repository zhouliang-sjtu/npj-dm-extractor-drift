# Extractor drift manufactures phantom longitudinal associations in text-mined health cohorts

Release snapshot for the npj Digital Medicine submission (branch `release/npj-dm-v1`, single commit, no internal history).

This repository contains the analysis code, the double-annotated gold-standard benchmark, all result artefacts, figures, prompts and the annotation codebook for the manuscript. The study measures how text-extraction agreement varies across calendar years in a seven-year health-checkup cohort (2018–2024, 30,677 individuals, 121,220 classifiable ECG narratives), shows that documentation drift combined with a never-approved outcome-aggregation rule can manufacture phantom longitudinal associations, and releases a frozen-extractor governance protocol (calibration → acceptance → monitoring → re-calibration).

Pre-registration: OSF `10.17605/OSF.IO/KUMVE` (sampling plan, acceptance gates, extractor comparison and falsification rule; registration timing statement included).

**A file-by-file index with manuscript cross-references (every table/figure/number → its source artefact) is in [INDEX.md](INDEX.md).**

## Repository layout

```

data/     Gold-standard benchmark: sampled reports, narrative text, pseudo-identifiers, extractor manifest, frozen-release database manifest, archived raw LLM responses
results/  Agreement, acceptance, drift-monitor, definition-alignment, bias-grid, replay and audit artefacts referenced by the manuscript
figures/  Figures 1–6 and Supplementary Figures S1–S3 (PNG 300 dpi + PDF)
docs/     prompts/   Frozen LLM prompts (ECG v1, cardiac-ultrasound v2.1; SHA-256 prefixes registered in data/extractor_manifest.json)
          codebook/  Annotation manual v1.0/v2.0/V3.0, column definitions, dataset descriptions (MD + PDF; authored in Chinese at the source institution — English summaries are given in the manuscript Methods and Supplementary Methods)
```

## Data (CC BY-NC 4.0)

- `data/gold_ecg_H.csv` (n=570), `data/gold_abdus_H_300.csv`, `data/gold_abdus_PG_300.csv`, `data/gold_echo_PG_300.csv` (n=300 each; the 600-report rule-stratified sampling parents are reproducible from `code/01_*` and are not redistributed).
- Every record carries `sample_id` (release join key), `pseudo_id` (12-character salted-hash person key generated by the data provider before delivery; the salt is not distributed), `text` (verbatim de-identified narrative), year/exam date, and annotation columns in the workbook. No direct identifiers are included; the 600-report community-cohort sampling frame is not part of this release.
- The adjudicated gold standard is in `data/gold_annotation_workbook_final.xlsx` (final double-annotation workbook with the outcomes of two arbitration rounds; 4 sheets, 1,470 reports).
- `results/pii_scan_summary.csv` documents the automated PII screening applied before release.

## Code (MIT)

Naming map: the manuscript's **dictionary v1** and **dictionary v3** correspond to dict v1/v3 in `code/07_dict_v3_rerun.py` and `code/main.py extract-ecg`. An internal intermediate v2 existed only for exploratory annual-rate tabulations during protocol development and was superseded by v3 before the validation study; it never entered the analysis database and is not part of this release.

Key entry points: `main.py` (unified CLI), `01_*` sampling, `04_agreement_stats.py` (κ/AC1/F1), `23_m2d_acceptance.py` / `29_ecg_acceptance.py` (acceptance gates), `B30_drift_monitor_crosslib.py` (gold-standard-free drift monitor + cross-library negative control), `B31_definition_alignment.py` (mixed vs definition-matched agreement; Tables 1–2), `B38_leave2023_sensitivity.py` (production/adjudicated association grid), `B27_probabilistic_qba.py` + `27_m5b_simex_backfill.py` + `33_grid_simcheck.py` (κ→HR QBA grid), `B28_version_contrast_equivalence.py` (paired-bootstrap version equivalence), `B29_specification_curve.py` (specification curve), `30_audit_verify.py` + `51_final_consistency_check.py` (number-audit and submission-consistency machine checks). LLM serving is local (Ollama 0.24.0; Qwen2.5-14B/7B-Instruct, GLM-4-9B; temperature 0, seed 42); determinism holds within identical software/hardware environments and is not guaranteed bit-for-bit across runtimes.
