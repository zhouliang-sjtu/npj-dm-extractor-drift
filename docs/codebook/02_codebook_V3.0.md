# 标注手册（Codebook）

> **发布说明**：版本号 **V3.0（冻结版）**，发布日期 2026-09-17。发布原因：依据 Stage 2 定义对齐判读（主包 170 例双盲判读＋仲裁裁定＋共认例全量复核）的最终结果修订，新增 ECG **结局归类（复合结局）条款**并闭合两条定义口径；《标注手册 V2.0》与《V2.1 附录：定义对齐判读指引》内容并入本版，全部改动见文末《v3.0 修订记录》，阈值类规则**含等于**。**本版为金标准冻结口径**，后续 LLM 抽取 prompt 对齐与论文方法学描述均以本版为准。

> 原则：标注/判读只按本手册规则执行；本版为终版，如遇本手册未覆盖情形，一律 `flag=1`＋`note` 留痕，不再口头裁定。

## 域① H社区ECG（输入：ecg\_text，一段结论文本）

输出列（多标签，各 0/1）＋ 结局归类列（1/2/0，见"结局归类（复合结局）条款"）：

| 列               | 定义         | 判定规则                                                                                                                             |
| --------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ecg\_normal     | 正常心电图      | 含"正常心电图/大致正常/未见明显异常/正常范围"，且无任何下述异常。**v3.0：本列语义为"显式正常表述"，与 ecg\_outcome 不要求相等（见条款④边界例）** |
| ecg\_af         | 房颤/房扑      | 房颤、心房颤动、心房扑动、房扑（不含"窦性"）                                                                                                          |
| ecg\_pac\_pvc   | 早搏         | 早搏、期前收缩、过早搏动（房性/室性均标1，无需区分）                                                                                                      |
| ecg\_stt        | ST-T/缺血    | ST-T改变、ST段（抬高/压低）、T波（低平/倒置/高尖）、心肌缺血；**"未见ST-T改变"=0；v3.0：T波高尖即使孤立出现（如"TV2、V3高尖"）亦判1** |
| ecg\_avblock    | 房室传导阻滞     | 一/二/三度房室传导阻滞、Ⅰ/II/III度AVB                                                                                                        |
| ecg\_bbb        | 束支/室内阻滞    | 左/右束支传导阻滞、分支阻滞、室内传导阻滞；**v3.0：不区分完全/不完全性（"不完全性右束支阻滞"判1）** |
| ecg\_rate       | 心率异常       | 窦性心动过速（>100）、窦性心动过缓（<60）；窦性心律（60-100）不算；v2：房颤/房扑伴快速心室率（"快速型/心室率快"）=1；非窦性心动过速（如非阵发性交界区心动过速）不算；**v3.0：窦速/窦缓孤立出现（无其他内容）亦判1** |
| ecg\_srirr      | 窦性心律不齐     | 窦性心律不齐/窦性心动不齐（含错别字变体）                                                                                                            |
| ecg\_axis       | 电轴/转位/低电压  | 电轴左偏/右偏、顺/逆钟向转位、低电压；**v3.0："左心室（高）电压"不属本列"低电压"同类描述，本列恒为0** |
| ecg\_qwave\_mi  | 异常Q波/陈旧性心梗 | 异常Q波、病理性Q波、陈旧性下壁/前壁梗死                                                                                                            |
| ecg\_other      | 其他器质异常     | 预激、逸搏、起搏器、房室分离、肥大/肥厚、紊乱性心律等；v2：窦房阻滞、房室连接处（交界区）心动过速列入本列；**"左心室（高）电压"不算（无器质含义）；"早期复极（综合征）/ST段J点抬高提示早期复极"属正常变异，不计入本列；v3.0：未列举的描述（如"胸导联R波递增不良"）按本列兜底时须在note留痕** |
| ecg\_unreadable | 无法判读       | 文本缺失/×/弃检/拒检/图像质量差；文本与所属域不符（错配，如尿检/腹超文本出现在心电图基）按无法判读=1，并在note反馈数据源 |

### 结局归类（复合结局）条款——ecg\_outcome（v3.0 新增）

**定义**：对每条 ECG 结论文本给出单一三分类结局，用于纵向队列分析的结局变量：**1=正常 / 2=异常 / 0=无法判读**。

**推导规则（确定性）**：

```
若 任一异常 flag（af/pac_pvc/stt/avblock/bbb/rate/srirr/axis/qwave_mi/other）=1 → ecg_outcome = 2
否则若 ecg_unreadable = 1                                          → ecg_outcome = 0
否则                                                              → ecg_outcome = 1
```

**判读顺序建议**（人工判读时）：先扫异常词句（→2）→ 再看显式正常表述与正常变异/无器质含义发现（→1）→ 再考虑 unreadable 情形（→0）。

**明文裁定条款**（本轮仲裁结果，均已按推导规则闭合）：

1. **仅节律描述→正常**：完整结论仅载"窦性心律"一行、无任何异常词句与显式正常表述者，判**正常（1）**（窦性节律本身属无器质含义的节律描述，临床报告惯例中单独"窦性心律"即未见其他异常）；
2. **左心室（高）电压→正常**：该描述不计入任何异常 flag，孤立出现（伴窦性心律）时判**正常（1）**；若合并其他真实异常（如 ST-T 改变、窦缓、肥厚），按异常 flag 判 2，与本条不冲突；
3. **孤立节律异常维持异常**：窦性心动过缓/过速、T波高尖、不完全性右束支阻滞等孤立出现时判**异常（2）**——手册明文优先于"可见于正常变异"的临床直觉；
4. **域错配/图像质量差→无法判读**：非心电内容出现在心电图域（原因选 2）、图像质量差/建议复查重做（原因选 3），均判 **0**。

**判 0 原因分类（v3.0 更新）**：1=文本缺失/弃检/拒检/×；2=疑似非心电内容（域错配）；3=图像质量差或其他（备注说明）。

边界例：

- "窦性心律，一度房室传导阻滞，部分导联ST-T改变" → avblock=1, stt=1, outcome=2
- "未见ST-T改变，心电图大致正常" → normal=1, outcome=1
- "窦性心动过缓伴不齐（58bpm）" → rate=1, srirr=1, outcome=2
- "电轴不偏" → 不算axis异常
- **"窦性心律"（仅此一行）** → 各异常flag=0、normal=0，**outcome=1**（条款1；ecg\_normal 与 outcome 不相等属预期，不得"倒改"flag）
- **"1.窦性心律 2.左心室高电压"** → 各异常flag=0、normal=0，**outcome=1**（条款2）
- **"窦性心律\nTV2、V3高尖"** → stt=1，**outcome=2**（条款3）
- **"1.窦性心律 2.不完全性右束支阻滞"** → bbb=1，**outcome=2**（条款3）
- **"尿潜血2+(80)。"（出现在心电图域）** → unreadable=1（原因2），**outcome=0**
- **"窦性心律\n图像质量差，建议复查"** → unreadable=1（原因3），**outcome=0**

## 域② PG心脏echo（输入：echo检查所见全文）

输出列：

| 列                | 定义      | 判定规则                                                                                          |
| ---------------- | ------- | --------------------------------------------------------------------------------------------- |
| echo\_normal     | 结构功能无异常 | 无任何下述异常，且瓣膜仅"未见/无"；心包积液（心包腔液性暗区）、心腔内性质待定的异常回声属结构异常 → echo\_normal=0（不属既列变量时 flag=1 说明） |
| echo\_variant    | 少量/轻微返流 | 仅"少量/轻度/轻微"返流，无结构异常                                                                           |
| echo\_lvh        | 左室肥厚    | 室间隔或左室后壁厚度**≥12mm（含等于，实测12mm即判1）**，或明确写"室间隔/左室壁增厚"；二尖瓣/主动脉瓣增厚不算                       |
| echo\_la\_dilate | 左房增大    | 左房内径**≥40mm（含等于，实测40mm即判1）**，或明确"左房增大/扩大"；**阈值仅适用前后径/上下径（任一达阈值即阳性）；左房左右径（横径/左右内径）仅作描述、不计入 40mm 阈值**——仅左右径超 40mm 而前后径/上下径均未达阈值、也无"增大/扩大"字样时判 0 |
| ef\_value        | EF数值    | 抽取"射血分数（EF）：67"中的数字；无则空                                                                       |
| ef\_abnormal     | EF<50   | 1/0                                                                                           |
| reflux\_grade    | 返流分级    | none/trace\_mild(少量·轻度·轻微)/moderate(中量)/severe(大量)；"未见返流"=none；**多瓣膜返流并存时取最重级别** |
| echo\_rhythm     | 节律异常    | 房颤/早搏/起搏/传导阻滞等任一                                                                              |
| echo\_unreadable | 无法判读    | 同上                                                                                            |

边界例：

- "二尖瓣后叶增厚、回声增强" → 不算LVH（瓣膜增厚），若有中度返流则reflux=moderate
- "左房内径约41mm，余房室大小正常" → la\_dilate=1
- 唯一仅左右径超标个案（前后径39mm、左右内径45mm、无"增大"字样）→ la\_dilate=0
- "肝实质细密"出现在echo文本中 → 忽略（肝所见不属于echo域）

## 域③ 腹部超声（输入：超声所见文本＋主检结果，两列分别标注后以超声所见优先）

输出列：

| 列                  | 定义       | 判定规则                                                                                |
| ------------------ | -------- | ----------------------------------------------------------------------------------- |
| us\_fatty          | 脂肪肝      | 明确"脂肪肝"；**描述式阳性**：实质回声细密(增强)+后方衰减+管道欠清 三要素≥2即判阳性                                    |
| us\_fatty\_degree  | 分度       | 轻/中/重（原文出现才标，否则空）                                                                   |
| us\_hepatic\_other | 其他肝病     | 血吸虫性肝病、肝囊肿(>10mm)、血管瘤、占位、肝硬化；肝内未定性结节/占位（>20mm）计入本列；肝内钙化灶计入本列                 |
| us\_gallstone      | 胆系       | 胆囊/胆管结石、息肉(记note大小)；胆管结石明确计入本列                                               |
| us\_kidney\_cyst   | 肾囊肿      | 含"左/右/双"记note                                                                       |
| us\_unreadable     | 无法判读     | ×/弃检/无文字                                                                            |
| main\_discrepant   | 主检与超声不一致 | 主检结果有/无脂肪肝与**本次超声所见**矛盾时=1；主检脂肪肝结论引自其他影像（CT/MRI附见）而本次超声未见 → 不算矛盾（=0，可flag说明） |

边界例：

- "肝实质回声细密增强，后方轻度衰减，管道结构欠清" → fatty=1（三要素3/3）
- "肝实质回声呈网络状、门脉管壁增厚（血吸虫肝病）" → fatty=0, hepatic\_other=1
- "回声不均匀"单独出现 → 不判脂肪肝，flag=1

## 通用规则

1. **否定优先**：先扫"未见/无明显/无/不厚/不增宽"及其后8字窗口，命中则该异常=0
2. **多标签并存**：一个文本可同时标多个异常列
3. **不确定**：`flag=1`+`note`写明原因（每份标注flag率预期<5%；>10%请停下反馈手册）
4. **速度**：ECG目标\~40s/份，echo/腹超\~90s/份；不追求零犹豫，仲裁机制兜底
5. **盲法**：标注时不得查看LLM/词典的预填结果（工作簿中不提供）
6. **结局归类列**（仅 ECG 域）：ecg\_outcome 按上方推导规则计算，不得与 flag 矛盾；发现矛盾按 flag 优先原则自查并反馈
