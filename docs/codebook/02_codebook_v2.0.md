# 标注手册（Codebook）

> **发布说明**：版本号V2.0，发布原因：依据首轮双标注+仲裁意见修订，全部改动见文末《v2.0 修订记录》，阈值类规则**含等于**。发布日期 2026-09-03，**补发用于标注员 A1/A2 间隔≥3 天的重复标注**。

> 原则：重复标注只按本手册规则标注，请标注员不要再使用或者回忆v1.0版本标注手册。

## 域① H社区ECG（输入：ecg\_text，一段结论文本）

输出列（多标签，各0/1）：

| 列               | 定义         | 判定规则                                                                                                                             |
| --------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ecg\_normal     | 正常心电图      | 含"正常心电图/大致正常/未见明显异常/正常范围"，且无任何下述异常                                                                                               |
| ecg\_af         | 房颤/房扑      | 房颤、心房颤动、心房扑动、房扑（不含"窦性"）                                                                                                          |
| ecg\_pac\_pvc   | 早搏         | 早搏、期前收缩、过早搏动（房性/室性均标1，无需区分）                                                                                                      |
| ecg\_stt        | ST-T/缺血    | ST-T改变、ST段（抬高/压低）、T波（低平/倒置/高尖）、心肌缺血；**"未见ST-T改变"=0**                                                                             |
| ecg\_avblock    | 房室传导阻滞     | 一/二/三度房室传导阻滞、Ⅰ/II/III度AVB                                                                                                        |
| ecg\_bbb        | 束支/室内阻滞    | 左/右束支传导阻滞、分支阻滞、室内传导阻滞                                                                                                            |
| ecg\_rate       | 心率异常       | 窦性心动过速（>100）、窦性心动过缓（<60）；窦性心律（60-100）不算；**v2：房颤/房扑伴快速心室率（"快速型/心室率快"）=1；非窦性心动过速（如非阵发性交界区心动过速）不算**                                 |
| ecg\_srirr      | 窦性心律不齐     | 窦性心律不齐/窦性心动不齐（含错别字变体）                                                                                                            |
| ecg\_axis       | 电轴/转位/低电压  | 电轴左偏/右偏、顺/逆钟向转位、低电压                                                                                                              |
| ecg\_qwave\_mi  | 异常Q波/陈旧性心梗 | 异常Q波、病理性Q波、陈旧性下壁/前壁梗死                                                                                                            |
| ecg\_other      | 其他器质异常     | 预激、逸搏、起搏器、房室分离、肥大/肥厚、紊乱性心律等；**v2：窦房阻滞、房室连接处（交界区）心动过速列入本列；"左心室（高）电压"不算（属axis低电压同类描述，无器质含义）；"早期复极（综合征）/ST段J点抬高提示早期复极"属正常变异，不计入本列** |
| ecg\_unreadable | 无法判读       | 文本缺失/×/弃检/拒检/图像质量差；**v2：文本与所属域不符（错配，如腹超文本出现在心电图基）按无法判读=1，并在note反馈数据源**                                                           |

边界例：

- "窦性心律，一度房室传导阻滞，部分导联ST-T改变" → avblock=1, stt=1
- "未见ST-T改变，心电图大致正常" → normal=1
- "窦性心动过缓伴不齐（58bpm）" → rate=1, srirr=1
- "电轴不偏" → 不算axis异常

## 域② PG心脏echo（输入：echo检查所见全文）

输出列：

| 列                | 定义      | 判定规则                                                                                          |
| ---------------- | ------- | --------------------------------------------------------------------------------------------- |
| echo\_normal     | 结构功能无异常 | 无任何下述异常，且瓣膜仅"未见/无"；**v2：心包积液（心包腔液性暗区）、心腔内性质待定的异常回声属结构异常 → echo\_normal=0（不属既列变量时 flag=1 说明）** |
| echo\_variant    | 少量/轻微返流 | 仅"少量/轻度/轻微"返流，无结构异常                                                                           |
| echo\_lvh        | 左室肥厚    | 室间隔或左室后壁厚度\*\*≥12mm（含等于，实测12mm即判1）\*\*，或明确写"室间隔/左室壁增厚"；**二尖瓣/主动脉瓣增厚不算**                       |
| echo\_la\_dilate | 左房增大    | 左房内径\*\*≥40mm（含等于，实测40mm即判1，含前后径/上下径任一达阈值）\*\*，或明确"左房增大/扩大"                                   |
| ef\_value        | EF数值    | 抽取"射血分数（EF）：67"中的数字；无则空                                                                       |
| ef\_abnormal     | EF<50   | 1/0                                                                                           |
| reflux\_grade    | 返流分级    | none/trace\_mild(少量·轻度·轻微)/moderate(中量)/severe(大量)；"未见返流"=none                                |
| echo\_rhythm     | 节律异常    | 房颤/早搏/起搏/传导阻滞等任一                                                                              |
| echo\_unreadable | 无法判读    | 同上                                                                                            |

边界例：

- "二尖瓣后叶增厚、回声增强" → 不算LVH（瓣膜增厚），若有中度返流则reflux=moderate
- "左房内径约41mm，余房室大小正常" → la\_dilate=1
- "肝实质细密"出现在echo文本中 → 忽略（肝所见不属于echo域）

## 域③ 腹部超声（输入：超声所见文本＋主检结果，两列分别标注后以超声所见优先）

输出列：

| 列                  | 定义       | 判定规则                                                                                |
| ------------------ | -------- | ----------------------------------------------------------------------------------- |
| us\_fatty          | 脂肪肝      | 明确"脂肪肝"；**描述式阳性**：实质回声细密(增强)+后方衰减+管道欠清 三要素≥2即判阳性                                    |
| us\_fatty\_degree  | 分度       | 轻/中/重（原文出现才标，否则空）                                                                   |
| us\_hepatic\_other | 其他肝病     | 血吸虫性肝病、肝囊肿(>10mm)、血管瘤、占位、肝硬化；**v2：肝内未定性结节/占位（>20mm）计入本列；肝内钙化灶计入本列**                 |
| us\_gallstone      | 胆系       | 胆囊/胆管结石、息肉(记note大小)；**v2：胆管结石明确计入本列**                                               |
| us\_kidney\_cyst   | 肾囊肿      | 含"左/右/双"记note                                                                       |
| us\_unreadable     | 无法判读     | ×/弃检/无文字                                                                            |
| main\_discrepant   | 主检与超声不一致 | 主检结果有/无脂肪肝与**本次超声所见**矛盾时=1；**v2：主检脂肪肝结论引自其他影像（CT/MRI附见）而本次超声未见 → 不算矛盾（=0，可flag说明）** |

边界例：

- "肝实质回声细密增强，后方轻度衰减，管道结构欠清" → fatty=1（三要素3/3）
- "肝实质回声呈网络状、门脉管壁增厚（血吸虫肝病）" → fatty=0, hepatic\_other=1
- "回声不均匀"单独出现 → 不判脂肪肝，flag=1

## 通用规则

1. **否定优先**：先扫"未见/无明显/无/不厚/不增宽"及其后8字窗口，命中则该异常=0
2. **多标签并存**：一个文本可同时标多个异常列
3. **不确定**：`flag=1`+`note`写明原因（每份标注flag率预期<5%；>10%请停下反馈手册）
4. **速度**：ECG目标\~40s/份，echo/腹超\~90s/份；不追求零犹豫，仲裁机制兜底
5. **盲法**：标注时不得查看LLM/词典的预填结果（工作簿中不提供）
